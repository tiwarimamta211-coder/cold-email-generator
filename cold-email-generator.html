📘 Cold Email Generator — Hindi Guide

Is tool ko use karne ka poora tarika

1. Ye tool kya karta hai?

Ye tool aapke liye AI ki madad se professional cold email likhta hai — job application, sales pitch, freelance proposal, ya investor outreach ke liye. Aapko bas kuch details bharni hain.

2. Steps

  1. Email Type choose karo — kis purpose ke liye email chahiye.
  2. Recipient details daalo — naam aur company/role (optional but recommended).
  3. Apni details aur Key Points bharo — ye sabse zaroori step hai. Jitna specific likhoge, email utna better banega.
  4. Tone aur Length select karo.
  5. "Generate Cold Email" button dabao.
  6. Email ko copy karo, edit karo, ya .txt file download karo.

3. Demo Mode vs Live Mode

Bina API key ke tool "Demo Mode" mein sample emails banata hai (templates based). Agar aap apna Claude API key daalte ho (Settings mein), toh tool real AI se personalized email generate karega.

4. Follow-up Email

Agar recipient reply na kare, "Generate Follow-up" button se ek polite Day-3 follow-up email bhi mil jaata hai.

5. Tips for Better Results

  • Numbers aur achievements mention karo (e.g. "30% revenue growth")
  • Ek clear Call-To-Action zaroor likho
  • Recipient ka naam pata ho toh use karo — personalization se reply rate badhta hai
  • Subject line short aur curiosity-driven rakho

6. Monetization Note (for tool owners)

Ye tool AdSense placeholder slots ke saath aata hai. Aap Razorpay integration add karke premium features (unlimited generations, PDF export, CRM integration) paid bana sakte ho.
